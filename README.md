# Cdc

`cdc` — учебный C-компилятор на Rust, который генерирует x86-64 assembly (`.s`).

## Важно про Windows 95

Собрать на этом компиляторе целиком Windows 95 пока нереально: для этого нужны почти полный C89-компилятор, препроцессор, линковка с системными ABI, заголовки/библиотеки и много другой инфраструктуры.

Но этот шаг сильно приближает проект к «настоящему» компилятору.

## Что теперь поддерживается

- Функция `int main() { ... }`
- Операторы:
  - арифметика: `+ - * /`
  - сравнения: `== != < <= > >=`
  - присваивание: `a = expr`
- Унарные `+` и `-`
- Локальные переменные: `int x;`, `int x = expr;`
- Выражения-операторы: `expr;`
- Блоки `{ ... }`
- `if (...) ... else ...`
- `while (...) ...`
- `return expr;`
- Комментарии `// ...` и `/* ... */`

## Улучшения лексера

- Поддержка multi-char операторов: `==`, `!=`, `<=`, `>=`
- Координаты ошибок `line:col`
- Ошибка на незакрытый block comment

## Сборка

```bash
cargo build --release
```

## Использование

```bash
./target/release/cdc input.c -o output.s
```

## Пример

```c
int main() {
    int i = 0;
    int s = 0;
    while (i < 5) {
        s = s + i;
        i = i + 1;
    }
    if (s == 10) {
        return 42;
    } else {
        return 1;
    }
}
```

```bash
./target/release/cdc example.c -o example.s
gcc -no-pie example.s -o example
./example
echo $?   # 42
```
