# Cdc

`cdc` — минимальный компилятор подмножества C в x86-64 assembly (`.s`), написанный на Rust.

## Что поддерживается

Только программа вида:

```c
int main() { return <expr>; }
```

Где `<expr>` может содержать:

- целые числа (`123`)
- `+`, `-`, `*`, `/`
- унарные `+` и `-`
- скобки

## Улучшенный лексер

Лексер:

- отслеживает позицию токенов (`line:col`) для точных сообщений об ошибках;
- пропускает `// line comments`;
- пропускает `/* block comments */` и ругается на незакрытые блок-комментарии;
- отклоняет неподдерживаемые идентификаторы (кроме `int`, `main`, `return`).

## Сборка

```bash
cargo build --release
```

## Использование

```bash
./target/release/cdc input.c -o output.s
```

Если `-o` не указан, файл будет создан рядом с исходником (`input.s`).

## Пример

`example.c`:

```c
int main() { return (2 + 3) * 4 - 5; }
```

Компиляция и запуск:

```bash
./target/release/cdc example.c -o example.s
gcc -no-pie example.s -o example
./example
echo $?   # 15
```
